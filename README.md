# Growth MS public website

The public marketing website for Growth MS and Solo Business OS. The paid application and its delivery ZIP are **not** in this repository.

GitHub Pages uses a custom Actions workflow. `growth-ms-public-site.zip` contains only the static website (26 public files, including the original Growth MS logo and screenshots). `verify-and-extract.py` checks its checksum, exact file list, paths and sensitive-source markers before extracting the public site. Only that extracted directory is deployed. The archive is a website release bundle, not the paid product.

Website: https://growthms.dev/ — Product page: https://growthms.dev/solo-business-os/

Checkout and advertising tracking are disabled until the owner configures them. Legal policy pages visibly indicate that they are pending review. No Purchase event is generated by this static site.

To update: edit the maintained local Growth MS website, run `python tools/build.py` and `python tools/export-release.py`, then upload the new public ZIP and its generated verifier together. The workflow publishes main. In repository Settings → Pages choose GitHub Actions and set the custom domain to growthms.dev. Never upload the private paid-product folder or use it as a build input.
